# Sweet Rush — кондитерская на двоих

Браузерный 3D-прототип кооперативной кулинарной игры для двух игроков на одном планшете. Ориентация экрана горизонтальная, управление multi-touch. Визуальный ориентир — темп и ощущение Overcooked! 2. Персонажи, модели, интерфейс, звук и музыка собственные: всё сделано процедурно в коде, ассетов оригинала нет.

**Все файлы лежат в одной папке, подпапок нет.**

## Как играть

- **Игрок 1 — медвежонок Бриошь** (коралловое кольцо) управляется в левой половине экрана. **Игрок 2 — зайка Зефирка** (синее кольцо) — в правой.
- Палец в любом месте своей половины создаёт джойстик, по нему персонаж ходит. Большая круглая кнопка выполняет действие. Подпись на кнопке подсказывает, что произойдёт.
- Путь блюда: **ящик с тестом → духовка (8 с) → топинг → тарелка → окно «ВЫДАЧА»**.
- Рецепты: круассан с корицей, шоколадный, шоколад + посыпка, с вареньем. Засчитывается только точное совпадение состава.
- После 9 секунд в духовке круассан начинает подгорать: мигает «!». На 14-й секунде он сгорает, это штраф. Сгоревший круассан отправляется в мусорку (тёмный люк слева).
- Предметы можно класть на любые свободные столы. Если смотреть на напарника с пустыми руками, предмет можно передать ему.
- Очки: монеты за заказ плюс чаевые за скорость. Чаевые умножаются на серию без ошибок (×1…×4). Штрафы: просроченный заказ −10, неверное блюдо −5, сгоревший круассан −10. Смена длится 4 минуты. Цели: ★ 100 · ★★ 220 · ★★★ 340.
- Клавиатура для проверки на ПК: игрок 1 — **WASD + Пробел**, игрок 2 — **стрелки + Enter**.

## Запуск

### Сразу играть
Откройте **`index.html`**. Это вся игра в одном файле: она работает без сервера и без интернета. Без интернета вместо фирменных шрифтов будут системные.

### GitHub Pages (папки не нужны)
1. Создайте репозиторий на GitHub.
2. **Add file → Upload files** — загрузите все файлы из этой папки (можно только `index.html`, этого достаточно для игры).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через минуту игра откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

На iPad: откройте ссылку в Safari, нажмите «Поделиться» → «На экран Домой». Если нет звука, проверьте беззвучный режим: он глушит звук в браузере.

### Разработка на Windows 10
1. Установите Node.js 20 LTS или новее с nodejs.org.
2. В этой папке выполните:
   ```
   npm install
   npm run dev
   ```
   Откроется `dev.html` — версия, которая сама перезагружается при правках. Для планшета используйте адрес `Network`, который напечатает Vite (та же Wi-Fi-сеть). Если планшет не открывает адрес, разрешите Node.js в брандмауэре Windows.
3. После правок выполните `npm run build`. Команда проверит типы и пересоберёт `index.html`. Потом загрузите новый `index.html` на GitHub.

## Почему свой рендер, а не Three.js

В среде, где собирался прототип, установка npm-пакетов была недоступна. Поэтому рендер написан с нуля на WebGL2, около 1500 строк. Всё, что есть в игре, запускалось и проверялось. Рендер отделён от игровой логики: переход на Three.js — это замена файлов рендера и графики, игровые модули почти не меняются.

## Модели

Все модели процедурные: скруглённые формы, вершинные цвета, узоры в шейдере. Кубических заглушек нет, но это и не работа 3D-художника. Для коммерческого уровня нужны модели в GLB (заказать, сделать в Blender или взять CC0-наборы Kenney / Quaternius) и переход на Three.js.

## Проверено

- Headless Chrome (WebGL через SwiftShader), экраны 1024×768, 1180×820, 1366×1024 и переход в портрет. Отдельно проверен браузер без `roundRect` (как Safari на iPadOS 15).
- Multi-touch через эмуляцию касаний. Два пальца ведут двух персонажей одновременно. Третий палец нажимает кнопку игрока 1, не сбивая джойстики. Палец, уехавший за середину экрана, продолжает управлять своим игроком. Потеря фокуса сбрасывает касания и ставит паузу.
- Полный цикл заказа, неверное блюдо, сгорание, мусорка, передача предмета, истечение заказов, конец смены, экран результатов, повтор. Ошибок в консоли нет.

**Не проверено:** реальный планшет и частота кадров на нём. На слабых устройствах включается автоадаптация: понижается разрешение, потом размер карты теней. Команды `npm install` и `npm run dev` в этой среде не запускались, `index.html` собран тем же сборщиком (esbuild) из этих же файлов.
